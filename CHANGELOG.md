# Changelog

## 1.0.0.1 - 2026-03-29

### Added
- Added a sticky header with a frosted-on-scroll state, mobile fullscreen navigation overlay, focus trapping, escape handling, and anchor-based founder contact routing.
- Added a client-side FAQ accordion, reduced-motion-safe reveal wrapper, generated Open Graph and Twitter images, and a generated site icon.
- Added Playwright smoke coverage for desktop navigation, mobile navigation, FAQ keyboard behavior, reduced-motion readability, and metadata asset resolution.
- Added a GitHub Actions workflow to run the Playwright smoke suite on pushes and pull requests.

### Changed
- Updated the homepage content flow with a founder CTA in `HowWeHelp`, a split founder/investor footer contact area, and a proof callout above the portfolio list.
- Tightened mobile responsiveness for the hero logo, team grid, thesis pills, and anchor offsets beneath the sticky header.
